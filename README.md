# 📊 Store Management Dashboard (Excel)

## 📌 Overview
This is my first Data Analytics project where I built an interactive **Store Management Dashboard** in Excel. 
The goal of this project is to analyze store performance, identify top-selling product categories, and evaluate regional branch sales.

---

## 📊 Key Insights
- **Total Revenue:** EGP 43.6M with an average **Profit Margin of 40.1%**.
- **Top Categories:** **Electronics** generated the highest sales (~12.5M EGP), followed by **Home** and **Fashion**.
- **Top Branches:** **Mansoura** and **Mohandessin** achieved the highest regional performance.
- **Payment Methods:** Card and Digital Wallets accounted for the majority of customer transactions.

---

## 🛠️ Tools Used
- **Microsoft Excel:** Data Cleaning, Pivot Tables, Formulas, and Visualizations.
